# HF-PnP-test

用于热式界面传感器接近与接触载荷实验的本地浏览器制图工具。导入原始电压 CSV 与 marker 文件，编辑距离和力，校正接触原点，预览并导出两张响应曲线。

所有计算在本机进行，服务仅监听 `127.0.0.1`。无需云服务、账号或 API 密钥。原始文件不会被覆盖。

## 功能

- 距离响应图 g：校正距离 +2 → −1 mm，单路绝对电压。
- 接触响应图 h：0–5 N，或对应的接触压强 kPa。
- 支持 DOWN / UP 和 Ut1 / Ut2；通道选择会实际切换数据列，并写入文件名。
- 自动查找配套 marker；支持从表格粘贴距离与力两列，保留空力。
- 拖动、滑块或数值输入调整接触原点；逐点查看原始信号及稳态窗口。
- 调整图尺寸、字号、线宽、颜色、纵轴范围与 SD 误差棒。
- 导出可编辑文字 SVG、600 dpi PNG、PDF，以及可恢复的设置和逐点统计表。

仓库内示例是**合成数据**，仅供体验和软件测试，不代表实测结果。本工具不是已定稿论文图件的数据包。

## 安装与启动

主要支持 Windows，建议 Python 3.11。需要 NumPy、Matplotlib；Windows 标准 Python 安装通常自带文件选择器需要的 Tkinter。绘图默认 Arial，请确保系统有该字体。

在 PowerShell 中执行：

```powershell
git clone https://github.com/wqwshn/HF-PnP-test.git
cd HF-PnP-test
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py --open-browser
```

也可以在 GitHub 选择 **Code → Download ZIP**，解压后进入目录执行后三条命令。若已安装其他兼容 Python，可用 `python -m venv .venv` 替代 `py -3.11`。

安装完成后，双击 `start_ui.cmd` 即可后台启动；它优先使用本目录的 `.venv`，否则使用 PATH 中的 Python。首次使用推荐上面的前台命令，便于查看启动错误；前台运行时按 Ctrl+C 停止服务。

打开 <http://127.0.0.1:8769>。自动载入示例的地址为 <http://127.0.0.1:8769/?demo=1>。

非 Windows 环境可使用 `python app.py --open-browser`，文件选择器需自行提供 Tkinter，也可使用浏览器双文件上传。此仓库未完成非 Windows 平台验收。

## 操作步骤

1. **导入数据**：点击“选择原始 CSV”，工具自动找同目录的 `<原始文件名>_markers.csv`；未找到则继续选择 marker。也可点击“浏览器上传”，同时选择这两个 CSV。第一次体验可直接载入合成示例。
2. **选择记录信息**：选择 DOWN 或 UP，以及实际需要读取的 Ut1 / Ut2。方向作为记录标签和文件名，不会自动倒排数据。
3. **填写距离和力**：展开“粘贴或编辑距离 / 力”，按 marker 文件原顺序粘贴两列，点击“应用两列数据”。有表头或没有表头均可。力未读出时保留空白，不填 0。已有注释会预填。
4. **设置面积**：默认圆头直径 19 mm，对应面积 283.5287369865 mm²。修改直径后点击“计算面积”，或直接填写有效受压面积。h 可选力或压强；面积留空时使用力模式。
5. **调整原点**：在全距离预览中拖动指定接触位置，或修改 d₀ 输入框。原始坐标不变，g 使用 `d = d_raw − d₀`。DOWN / UP 可分别记住原点。
6. **检查稳态窗口**：默认取 marker 前 1 s。选择 marker 查看绿色取值区间，必要时修改当前点的独立窗口；清空即恢复默认。点击统计表中的行也能切换检查点。
7. **调整样式并导出**：修改宽高、字体大小、曲线颜色等，满意后点击导出。文字裁切或重叠时，增大画布或减小字号后重试。
8. **恢复设置**：先载入对应的原始与 marker 文件，再选择历史导出的 `settings.json`。匹配检查会拒绝来自不同源文件的设置。

## 输入 CSV 格式

文件使用 UTF-8，可带 BOM。原始 CSV 至少包含：

| 列 | 含义 |
|---|---|
| `Time(s)` | 严格递增的采样时间，秒 |
| `SampleIndex` | 严格递增的整数样本索引 |
| `Ut1(mV)`、`Ut2(mV)` | 两路电压，mV；当前解析器要求两列都存在 |
| `ValidFlag` | 可选，1 为有效；缺列时按 1 |
| `InterpFlag` | 可选，0 为非插补；缺列时按 0 |

marker CSV 示例：

```csv
SampleIndex,MarkerNo,Note-distance(mm),Note-force(N)
200,1,2.0,
300,2,-0.2,
400,3,-0.4,0.5
```

- `SampleIndex` 必须在原始文件中精确存在。
- `MarkerNo` 应唯一，省略该列时按行号生成。
- 两个 Note 列可缺失或留空，随后在 UI 中填写；完整匹配列名如上，兼容中文全角括号。
- `Elapsed(s)` 等其他列可保留，但不用于信号定位。
- 粘贴内容使用制表符或逗号分列，行数必须与 marker 数一致，按文件顺序对应；不要附加时间列。

## 计算规则与边界

电压由 mV 除以 1000 转为 V，不做基线扣除、归一化或平滑。窗口为 `[marker_time − window, marker_time)`，不含打标样本自身；完整 100 Hz、1 s 窗口有 100 个样本。

均值与样本标准差（SD，`ddof=1`）仅使用有限电压、有效且非插补的样本。SD 表示单次窗口内波动，不是重复实验之间的误差。窗口不完整时界面提示实际有效样本数。

压力换算为：

```text
A[mm²] = π × diameter[mm]² / 4
P[kPa] = 1000 × F[N] / A[mm²]
```

默认 19 mm 圆头时，5 N 对应约 17.635 kPa。面积必须与测力计总力的实际承载区域对应，不能直接用热膜电阻图案面积代替。圆头直径及接触条件不同，应修改参数。

负距离且无力读数的点仍用于 g，但不进入 h；空值不补成零。人工原点校正只做整体平移，不能独立确定真实接触瞬间，也不能消除随位置变化的回程误差。

曲线按采集顺序分段线性连接，保留实测点。仅在有实测点包围时补零点或显示边界的插值值，不外推、不生成新的实测点标记、不插值 SD。h 的轴从零开始，不代表补造了零力测量值。若载荷发生反向变化，曲线保留采集次序。

## 导出文件

导出写入 `exports/<原始名>_<方向>_<通道>_<时间戳>/`，每次新建目录。

| 文件 | 内容 |
|---|---|
| `*_g_*`、`*_h_*` 的 SVG / PNG / PDF | 两张独立图；不重复添加 panel 字母 |
| `settings.json` | 原始文件身份、粘贴数据、面积、原点、窗口和样式 |
| `points.csv` | 全部 marker 的坐标、力、压强、均值、SD、n 和窗口 |
| `figure_metadata.json` | 显示范围、可见点数、插值值和排版检查 |

默认单图尺寸 38.1 × 33.16 mm；PNG 为 600 dpi。SVG 保留文字及显式 Arial 属性；实际 Illustrator 导入效果仍需在目标环境核对。浏览器会记住部分设置，长期保存请以 JSON 为准。

## 测试与故障排查

```powershell
.\.venv\Scripts\python.exe -m unittest test_app -v
```

测试覆盖通道、窗口、缺失力、原点平移、压力换算、插值边界、无效样本、换行差异和 SVG 排版。测试使用仓库合成示例。

- **页面无法打开**：先以前台命令启动，检查控制台；后台方式查看 `server-error.log`。
- **端口占用**：改用 `python app.py --port 8770 --open-browser`，启动脚本仍默认使用 8769。
- **没有弹出文件选择框**：检查 Tkinter；使用浏览器上传并同时选择两个 CSV。
- **缺失字体**：安装 Arial；字体替换可能影响尺寸和导出效果。
- **导出按钮不可用**：确认粘贴修改已应用，参数有效，画布没有文字裁切或重叠。
- **设置恢复失败**：需匹配同一原始和 marker 文件，文件内容变动会改变身份。BOM 与 CRLF/LF 换行差异已规范化。

运行依赖仅为 Python、NumPy、Matplotlib。无需 Node.js、Codex 或 Playwright。实验数据、导出、日志和虚拟环境默认不进入版本控制。
